## Welcome to StageFlow

**StageFlow** is an open-source, web-based 3D camera-blocking and scene choreography diorama. It synchronizes a universal video player (**local video files**, **YouTube URLs**, or a **60fps procedural simulator**) with an interactive Three.js blueprint stage, allowing you to study, dissect, and visualize the spatial staging and camera maneuvers of film scenes at every millisecond.

StageFlow was born out of genuine curiosity about visual storytelling: *What does it actually mean to block a scene? How do camera moves, focal lengths, and performer staging interact to create meaning?* Rather than acting as a heavyweight production animatics tool, StageFlow is designed as an analytical sketchbook—stripping away visual clutter down to pure architectural geometry, sightlines, focal planes, and trajectories.

## What's New in v1.0.0

### 🎥 Dual-Camera Spatial Architecture
- **Stage Camera (Director's Viewfinder)**:
  - Projects a true-to-aspect rectangular pyramidal frustum matching your reference film gate (`16:9`, `2.39:1` anamorphic, etc.).
  - Features a sliding **Focus Plane Frame**, near/far Depth-of-Field limit brackets, and an emerald world-space tether for off-axis subject tracking.
  - Includes an opt-in, single-pass WebGL2 24-tap Vogel disk bokeh blur viewfinder shader (`[ Blur ]` / hotkey `B`).
- **Observer Camera (Macroscopic Viewport)**:
  - Plays scripted choreography trajectories smoothly in `'scripted'` mode.
  - Features an intuitive **pause-to-free-orbit handover**: the camera locks to the authored path during playback, and unlocks `OrbitControls` the instant playback is paused so you can freely orbit, pan, and inspect the frozen staging from any angle.
  - Instantaneous POV cuts ($0\text{ms}$) between `'scripted'`, `'free'`, and `'stage-pov'` modes.

### 📐 Choreography as Code (Declarative YAML Schema)
- Authored entirely in human-readable, version-controlled YAML scripts (`*.yaml`).
- **Stateless Functional Timeline (`Frame_t = f(t)`)**: Every millisecond of camera movement and actor blocking is purely deterministic. Scrubbing forward or backward yields bit-for-bit identical 3D states with zero cumulative drift.
- **11 Expressive Camera Maneuvers**: Static holds, push-in/pull-out dollies, tracking trucks, pedestals, pans, tilts, Dutch rolls, orbital sweeps, Catmull-Rom spline curves, swoops, and compound paths.
- **Contiguous Single-Take Takes ("Oners")**: Opt-in `continuous: true` chaining automatically links camera coordinates and actor positions across shot boundaries without teleports or snaps.
- **Two-Shot Centroid Framing**: Support for multi-subject targets (`target: ["detective", "witness"]`), dynamically resolving the 3D world-space midpoint and tracking walking actors at 60fps.

### ⏱️ Precision Universal Media Clock
- Universal synchronization parity across:
  - **Local Media**: Drag-and-drop `.mp4` and `.webm` files directly into the browser (processed 100% locally in-memory).
  - **YouTube Streams**: Frame-accurate sync via a custom 60fps `performance.now()` drift extrapolation engine.
  - **Blueprint Simulator**: Standalone 60fps virtual clock for studying scores without external video files.
- Remote score loading via query parameters (`?score=<catalog-id>` or `?url=<raw-yaml-url>`) with address bar hygiene.

### 🔍 Cinematic Optics & Thin-Lens Depth of Field
- Full-frame optical math ($36 \times 24\text{mm}$ sensor geometry) mapping real focal lengths (`24mm`, `35mm`, `50mm`, `85mm`) to vertical FOV.
- Thin-lens Gaussian Depth of Field with aperture presets (`shallow: f/2.8`, `medium: f/5.6`, `deep: f/∞`) and custom numeric $f$-stops.
- Cinematic rack focus pulls (`focus_start` $\to$ `focus_end`) and subject follow-focus.

### 🛞 Physical Camera Mounts & Dolly Tracks
- **Stationary Tripods**: Blueprint 3-legged stands with splayed legs, floor pucks, and vertical telescoping center columns.
- **Dolly Rails & Carts**: Physical dual-rail floor tracks ($0.42\text{m}$ standard gauge) with orthogonal cross-ties and a 4-wheeled dolly cart.
- **Catmull-Rom Spline Rails**: Curved camera tracks with smooth multi-waypoint guidance.

### 🧍 Directional Mannequins & 3D Spatial Dimensions
- Characters, set props, and spike marks with configurable 3D dimensions ($w, h, d$).
- Floor-pinned scaling ($Y = 0$) ensuring actors never sink into or float above the stage floor.
- Anatomically preserved head spheres and shoulder bars with telescoping torso columns for crouching and sitting postures.
- Shape-matched ground footprints (oriented rectangular bounding boxes for props, elliptical footprints for characters).

### 📋 Directorial Studio Shell & Scene Desk
- **Executive Scene Production Brief**: High-density overview showing scene premise notes (Markdown-enabled), 4-stat production metrics, lens package chips, and active maneuver tags.
- **Categorized Call Sheet & Roster**: Live inventory of characters, set props, and spike marks with dimension badges.
- **Dual-Camera Telemetry Capsule**: Bottom-right HUD with integrated `[ OBS | CAM ]` switcher and 1-click YAML snippet copying.
- **4 Curated Visual Themes**: Dark Obsidian (default), Pure Black, Light Stone, and Warm Paper.
- **Accessible Info Modal**: Press `?` anywhere to bring up shortcuts, creative intent notes, and documentation links.

### 🎬 Deterministic 60fps Headless Viewport Recorder CLI
- Built-in Node.js CLI (`npm run record`) powered by Playwright and FFmpeg.
- Exports pixel-perfect, 60fps MP4 or Apple ProRes (`.mov`) viewport choreography videos.
- Three recording viewpoints: Scripted Observer View, Stage Camera POV (Viewfinder), or Picture-in-Picture (Diorama + Viewfinder).
- Optional reference audio track syncing.

## Studio Keyboard Shortcuts

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Space` | **Play / Pause** | Toggle playback. Pausing unlocks free 3D orbit controls. |
| `[` / `]` | **Step Frame** | Step backward / forward by 1 video frame ($1/30\text{s}$). |
| `←` / `→` | **Scrub Timeline** | Scrub backward / forward by $1\text{s}$ (Hold `Shift` for $5\text{s}$). |
| `B` | **DoF Bokeh Blur** | Toggle single-pass WebGL2 Stage Cam viewfinder depth-of-field blur. |
| `G` | **Framing Guides** | Toggle rule-of-thirds and safe-action composition overlays. |
| `L` | **3D Label Mode** | Cycle mannequin label display mode (`all` $\to$ `key` $\to$ `off`). |
| `?` | **About & Shortcuts** | Open the About StageFlow dialog and documentation links. |

## Getting Started

### 1. Launch the Web Studio
Try the studio directly in any modern WebGL2-compatible browser (Chrome, Edge, Firefox, Safari):
👉 **[https://stageflow.taruma.my.id](https://stageflow.taruma.my.id)**

### 2. Run Locally
```bash
# Clone the repository
git clone https://github.com/taruma/stageflow.git
cd stageflow

# Install dependencies
npm install

# Start local development server
npm run dev
```

### 3. Record a 60fps Choreography Video
```bash
# Record bundled Blueprint 06 in 1080p 60fps
npm run record -- --score blueprint-06-optics-dof --camera observer --preset cinematic
```
